# WASM Showcase

A static site built with **GitHub Pages** and pure **Markdown**, exploring WebAssembly applications.

🔗 **Live site:** https://YOUR-USERNAME.github.io/YOUR-REPO/

## Files

- `index.md` — main page
- `diary.md` — learning diary with screenshots
- `_config.yml` — Jekyll config
- `screenshots/` — diary images

## Local preview (optional)

```bash
gem install bundler jekyll
jekyll serve
# open http://localhost:4000
```

You don't actually need to run Jekyll locally — pushing to `main` is enough.
